# Внешние основания и границы заимствований

[Оглавление](README.md)

Спецификация ris объединяет исходную методику от 8 октября 2026 года и уточнения текущего обсуждения. Формат конфигурации, именование, контракты и границы пакета являются нашими проектными решениями, а не стандартом стороннего продукта.

Официальные страницы Agent Skills и OpenCode о скилах повторно прочитаны 9 октября 2026 года. Файлы Pocock и Osmani были прочитаны через GitHub в ходе этого обсуждения. Для них ниже указаны пути и, где доступны, идентификаторы содержимого Git blob; это не номера релизов и не SHA всего репозитория.

Ссылки на `main` могут изменяться. При фактическом заимствовании или интеграции следует фиксировать используемый commit и проверять совместимость. Эти внешние сайты не являются обязательными runtime-зависимостями каждого запуска ris.

## S1. Agent Skills — Specification

Адрес: `https://agentskills.io/specification`

Основание: каталог с `SKILL.md`, YAML-метаданные `name` и `description`, дополнительные ресурсы, относительная адресация от скила и поэтапная загрузка. В прочитанном формате не определены универсальные исполняемые импорты, установка зависимостей или подстановка проектных параметров в Markdown.

Применение в ris: совместимая оболочка файлов; отдельный явный контракт собственных настроек. Базовое описание в [01](01-architecture.md), метаданные в [04](04-contracts-and-adapters.md).

## S2. Agent Skills — Adding skills support

Адрес: `https://agentskills.io/client-implementation/adding-skills-support`

Основание: различение обнаружения и активации, передача инструкций в контекст, доступ к ресурсам, управление контекстом и необязательное делегирование.

Применение в ris: название в каталоге не равно прочитанной инструкции; правила должны быть доступны конкретному исполнителю. Поведение загрузки описано в [03](03-composition.md), проверяется в [05](05-adoption-and-validation.md).

## S3. OpenCode — Agent Skills

Адрес: `https://opencode.ai/docs/skills/`

Основание: обнаружение каталогов и загрузка инструкций инструментом `skill`. Конкретные пути, права и поведение зависят от используемой версии среды.

Применение в ris: первая проверяемая интеграция — конкретная зафиксированная версия OpenCode; исходник пакета не считается установкой автоматически. Работоспособность в локальной среде пользователя этим чтением документации не проверена.

## S4. Matt Pocock — grill-with-docs и grilling

Адреса:

```text
https://github.com/mattpocock/skills/blob/main/skills/engineering/grill-with-docs/SKILL.md
https://github.com/mattpocock/skills/blob/main/skills/productivity/grilling/SKILL.md
https://github.com/mattpocock/skills/blob/main/docs/engineering/grill-with-docs.md
```

Прочитанные Git blob:

```text
grill-with-docs/SKILL.md: 62b9efb6f991d1b229adee7506962f13ced0c499
grilling/SKILL.md: df69d9936880cd3314c28858c6c52f48db23b856
```

Заимствованный принцип: прикладная точка входа может сочетать переиспользуемые методики; вопросы зависят от ранее определённых решений. В ris добавлены явные роли, область, форма применения и ответственность за общий результат. Предельная краткость обёртки и неограниченное исследование всех ветвей не копируются.

## S5. Matt Pocock — domain-modeling

Адрес: `https://github.com/mattpocock/skills/blob/main/skills/engineering/domain-modeling/SKILL.md`

Git blob: `a4438c6879c517d1a08e2b5fbca049b632688dfe`.

Заимствованы уточнение доменных понятий на конкретных сценариях, фиксация согласованных определений по ходу работы и избирательность ADR. В прочитанной методике ADR предлагается для труднообратимого, требующего контекста выбора между реальными альтернативами.

Отличие ris: глоссарий и ADR не заменяют сохранение требований; запись ограничивается разрешениями и выбранным хранилищем, а значимые решения передаются следующей сессии. См. [06](06-artifacts-and-handoff.md).

## S6. Addy Osmani — How Skills Work и Skill Anatomy

Адреса:

```text
https://github.com/addyosmani/agent-skills#how-skills-work
https://github.com/addyosmani/agent-skills/blob/main/docs/skill-anatomy.md
```

Git blob `docs/skill-anatomy.md`: `04e493326aa5f7ea8b87ce5ca8de9925147a802b`.

Заимствованы конкретная процедура, типичные необоснованные обходы, наблюдаемые признаки нарушения, критерии с подтверждениями, поэтапная загрузка и описания для выбора скила. В ris эти идеи встроены в контракт, но обязательные длинные таблицы не вводятся.

Не копируются жёсткие численные нормы, привязка универсальных инструкций к одному стеку и расположение общих ресурсов за пределами устанавливаемых скилов. Прочитанный документ автора прямо описывает риск потери корневого `references/` при выборочной установке.

## S7. Addy Osmani — Definition of Done

Адрес: `https://github.com/addyosmani/agent-skills/blob/main/references/definition-of-done.md`

Git blob: `35e39f9e15f6dd0ff4725a6e5cbce7f2aa69064a`.

Заимствовано различение критериев конкретной задачи и общего проектного стандарта готовности. В ris к ним добавляется контракт текущего скила, а применимость проверок различается для документа, изменения кода и релиза. Не требуется новый обязательный файл стандарта готовности.

## S8. Addy Osmani — Skill Evals

Адрес: `https://github.com/addyosmani/agent-skills/blob/main/evals/README.md`

Git blob: `4f501cdb0da265812458c43f2bc433b056fb357b`.

Заимствовано разделение структурных проверок, проверки выбора и проверки поведения, включая реальные действия и сценарии давления. Лексическая оценка описаний рассматривается как приближение, не как доказательство поведения модели.

В ris не копируются конкретный runner, модель, численные пороги или заявления о достигнутой точности. Нужна оценка в фактической среде проекта. План проверки приведён в [05](05-adoption-and-validation.md).

## Исходная редакция и граница утверждений

Основой служили файлы прежней «Методики организации комплекта SDLC-скилов» версии 1.0 от 8 октября 2026 года: README, документы 01–05, шаблоны, примеры общего слоя, контекста и подключения roadmap. Они были повторно прочитаны из предоставленной библиотеки перед подготовкой этой редакции.

Настоящий архив — полная согласованная замена документационной редакции, а не набор разрозненных поправок. Старые имена показаны только в [CHANGELOG.md](CHANGELOG.md) для перехода.

Внешние методики не являются доказательством эффективности ris. Наличие архива, ссылок и тестовых сценариев не означает, что реализация создана или поведенческие проверки пройдены. Фактически выполненные проверки самого архива перечислены в [validation-report.md](validation-report.md).
