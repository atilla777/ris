# Фрагмент для проектного AGENTS.md

[Оглавление](../README.md)

Этот блок добавляется в существующий `AGENTS.md` целевого проекта, а не заменяет его целиком. Он указывает на необязательный проектный `ris.yaml`, если проект его использует; без него действуют пакетные значения по умолчанию.

```markdown
## Пакет ris

Если проект использует собственные настройки, его полный файл `ris.yaml`
находится относительно каталога этого `AGENTS.md`. Иначе используй
пакетные значения по умолчанию RIS.

При выполнении скила ris обеспечь актуальные инструкции `ris-common`
в текущем контексте. Дополнительные ресурсы читай до соответствующих
действий по условиям, указанным в `ris-common`.

Для проектной операции подготовь настройки через `ris-context`,
если подходящий актуальный контекст ещё не получен.

Методику и границы этапа задаёт выбранный прикладной скил.
Порядок этапов и делегирование задаёт текущее задание или существующий workflow.
Не считай загрузку скила выполнением его операции.
Не подменяй явно выбранные пути и отсутствующие обязательные зависимости.

Применяй действующие проектные правила и ограничения среды.
Не выдавай сохранённый документ за принятый или проверенный автоматически.
```

Блок не дублирует адреса всех документов, правила диалога и команды CLI. Эти сведения имеют собственных владельцев.

Файл `AGENTS.md` репозитория разработки самого ris и `AGENTS.md` целевого проекта решают разные задачи. Инструкции для сопровождения ris нельзя автоматически копировать во все проекты-потребители.

Пользовательская команда или hook при необходимости добавляется тонкой интеграцией для конкретной среды. Этот фрагмент не гарантирует автоматическую загрузку любых упомянутых файлов и не заменяет проверку установки.
