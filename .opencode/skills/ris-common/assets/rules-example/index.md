# Illustrative project rules bundle

This is a **non-binding example**, not accepted rules of any project. It shows
one bundle with two subject owners; architecture is not a nested bundle.
Do not copy it wholesale to a project's normative paths or treat installation
as acceptance. Select applicable content from project facts and the relevant
base/profile, present the exact candidate and obtain scoped acceptance first.
